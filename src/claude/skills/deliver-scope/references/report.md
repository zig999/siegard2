# The report

Read after `handoff.py --prepare` has printed its skeleton; write what follows through
`--save-report`.

## What the report says, in order

Say, in this order, in the file:

1. Where `HEAD` stood when the run began.
2. Every commit this run made, by hash and message, and the `git log` range that holds them.
3. Every input you decided rather than were told — the slug derived, the target decided, the order
   taken — each disclosed.
4. Every step invoked with its outcome, and the path of `orchestration.md`.
5. Every line the last `deliver.py --outstanding` printed of records pinning no standard or another
   than their target declares, verbatim and as a fact.
6. The review's findings, relayed whole, with that report's own account of which passes did not run.
7. Which nodes this run left decided by a test, which certifications were refused again and with
   what remainder, and — for any testable remainder over a node no task of this run implements —
   `trace.py --owed`'s closing invocation, relayed.
8. The telemetry report the measure wrote, by path, or the line saying why it could not read.
9. What ended the run, where it ended early, with the stopping report's doors verbatim and its
   recommendation where it made one, and whether that report called it a judgment.
10. What you never did — no `/analyse`, no repair of any finding, no step beyond the route.
